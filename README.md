# Сравнение линейного и бинарного поиска

Домашнее задание: реализация бинарного поиска и его сравнительный анализ с линейным.

## 📌 Описание
Реализованы два алгоритма поиска: линейный (O(n)) и бинарный (O(log n)). 
Проведен анализ сложности, выполнены тесты на 100 элементах и построен 
график сравнения скорости работы на разных объемах данных.
